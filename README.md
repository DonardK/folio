# Folio

A private PDF reader. Add your own files in the browser. They stay on that device and are not uploaded.

The first page is always shown alone. After that, two-page view opens facing pages when you turn it on.

## Use it

Open the site, choose **Add PDFs**, and start reading. On a phone, add the books in that phone's browser. Name files so volume 2 sorts before volume 10.

Arrow keys, the on-screen buttons, and swipes turn pages. Tap the middle of the page to show or hide the controls.
