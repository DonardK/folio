# Folio

Add your own PDFs after signing in. They are saved on the site, so the same shelf and the page you left off on are there from any browser.

The first page is always shown alone. After that, two-page view opens facing pages when you turn it on.

## Use it

Open the site, sign in, and choose **Add PDFs**. Name files so volume 2 sorts before volume 10. **Where you left off** returns to the last page you were reading.

Arrow keys, the on-screen buttons, and swipes turn pages. Tap the middle of the page to show or hide the controls.
